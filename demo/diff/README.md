# demo/diff: the Diff page's cases

Inputs for `advtext/ui/pages/diff.py`. Each is a shape a coding agent's host is
handed (see `../pptmstr/pptmstr/approval.py`, `render_diff`), kept either as a
before/after pair or as the unified text a tool wrote.

| files | case | how the page builds it |
|---|---|---|
| `edit.before.py`, `edit.after.py` | `edit`: a small Edit | `Diff.from_texts(before, after, "retry.py")` |
| `new_file.py` | `new`: a Write of a new file | `Diff.from_texts(None, text, "limits.py")` |
| `deleted.sh` | `deleted`: a file removed | `Diff.from_texts(text, None, "setup.sh")` |
| `tokens.before.py`, `tokens.after.py` | `tokens`: whitespace-only and one-token changes | `Diff.from_texts` |
| `anchor.old.txt`, `anchor.new.txt` | `anchor`: an Edit whose anchor is not in the file | `Diff.from_texts(old, new, "client.py", will_not_apply="anchor not found in file")` |
| `multiedit.diff` | `multiedit`: three edits as pptmstr joins them | `Diff.from_unified(text)` |
| `git.diff` | `git`: four files as `git diff` prints them | `Diff.from_unified(text)` |

| `mail.patch` | `mail`: a `git format-patch` mail (hard case) | `Diff.from_unified(text)` |
| `combined.diff` | `combined`: a `diff --cc` merge diff (hard case) | `Diff.from_unified(text)`: flagged, shown as written |
| `unmarked.diff` | `fence`: a model's fragment whose context has no leading space (hard case) | `Diff.from_unified(text)` |

Two more hard cases have no file either and came from review 3: `unseen`
(`unseen_texts()`: a zero-width space, a right-to-left override, Greek and CJK,
written with `chr` so that no file here holds an invisible character) and `u0`
(`u0_text()`: an honest context-free diff, made by `difflib`, of a file whose
lines begin `-- ` and `++ `).

The three **hard-case** files, and four hard cases with no file (`nul`, `noeol`,
`noeol-text`, `eol`, generated by `control_texts()`, `noeol_edits()` and
`crlf_texts()` in the page module because a NUL byte and CRLF endings do not
survive editors and checkouts), are the inputs review 1 of the diff model found
a defect with (`.concerns/lead--demo-review1-findings.md`). They are written by
hand, not generated. `mail.patch` ends with a signature line that is two dashes
**and a trailing space**, and `combined.diff` has lines that begin with a space
and then a marker: an editor that strips trailing or leading whitespace changes
what they test. The hashes in both are made up.

Two more cases have no file: `long` (about four thousand lines, made from this
package's own modules) and `wide` (lines of 300 to 800 characters) are generated
by `long_texts()` and `wide_texts()` in the page module.

`tokens.before.py` contains **tab characters on purpose** (lines 12 and 13): the
change to spaces is the whitespace-only case. An editor that converts tabs on
save will quietly delete it; `tests/test_page_diff.py` checks they are there.

`multiedit.diff` and `git.diff` are generated, by
`.concerns/C-page-diff-scripts/make_cases.py.txt`, from the other files here and
a copy of pptmstr's `_unified`. The index hashes in `git.diff` are made up. If
`edit.*.py`, `new_file.py` or `deleted.sh` change, run it again -- the test that
compares `git.diff` with them will say so.

Nothing here is executed. `deleted.sh` and the `.py` files are text.
